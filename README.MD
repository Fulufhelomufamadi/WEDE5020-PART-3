# Tshiawelo Primary School Website

## Project Description
This project is a website developed for Tshiawelo Primary School, a public primary school located in Tshitungulwane Village, Vuwani, Limpopo.

The website provides information about the school, its academics, gallery, enquiries and contact details.

## Technologies Used
- HTML
- CSS
- JavaScript

## Website Pages
- Home
- About Us
- Academics
- Gallery
- Enquiry
- Contact Us
